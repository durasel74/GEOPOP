# GEOPOP — генератор геометрических аватарок
Процедурный генератор аватарок в стиле нео-брутализм / Баухаус. Без сборки, без зависимостей, без сервера — чистыеHTML + CSS + JavaScript.

## Быстрый старт
Скачай/склонируй папку проекта.
Открой index.html в браузере (двойной клик — этого достаточно).
Опционально можно поднять локальный сервер (нужен для гарантированной работы буфера обмена в некоторых браузерах):

python3 -m http.server 8000#
затем открой http://localhost:8000

## Структура проекта

geopop/├── index.html          — разметка и порядок подключения скриптов├── README.md├── css/│   └── style.css       — все стили└── js/    ├── core.js         — утилиты: ГПСЧ, цвета, фигуры, реестр VAR    ├── themes.js       — цветовые схемы (THEMES)    ├── variants/       — по одному файлу на тип элемента:    │   ├── bg.js       —   фоны    │   ├── emblem.js   —   эмблемы    │   ├── frame.js    —   рамки    │   ├── accents.js  —   акценты    │   └── overlay.js  —   оверлеи    ├── engine.js       — состояние, отрисовка, генерация, экспорт    ├── ui.js           — интерфейс: пейджеры, слои, галерея    └── main.js         — привязка событий и запуск
Порядок скриптов в index.html менять нельзя: core.js создаёт реестрVAR, файлы из variants/ наполняют его, engine.js рисует по реестру,ui.js строит интерфейс, main.js запускает всё.

## Как это работает

Аватарка собирается из 5 слоёв: фон → рамка → эмблема → акценты → оверлей.
У каждого слоя есть варианты (например, у эмблемы — лицо, планета,кассета…) и sub-seed — случайная раскладка внутри варианта.
Всё рисование детерминировано: пара (seed, настройки слоёв) всегда даётодну и ту же картинку. Поэтому в «Избранное» сохраняются параметры,а не картинки.
Тема задаёт палитру: bg (фон), ink (контур), a — основные цветапо ролям слоёв, x — дополнительные цвета для ручного выбора.

## Как добавить цветовую схему
Открой js/themes.js, скопируй любой блок и поменяй значения:

 {id:'mytheme', name:'Моя', bg:'#F6F1E7', ink:'#17151C',  a:['#FF5C39','#FFC940','#17A398','#FF4D8D'],   // эмблема, рамка, фон, доп.  x:['#FFFFFF', /* ещё 7 сочетающихся цветов */]},
Карточка в пейджере тем появится автоматически (6 тем = 1 страница).

## Как добавить вариант элемента
Открой нужный файл в js/variants/ (фон — bg.js, эмблема — emblem.js…)и добавь объект в конец массива:

 {id:'myvar', name:'МОЁ', draw(ctx,col,t,rng){    // col — цвет слоя, t — тема (t.bg/t.ink/t.a), rng — ГПСЧ варианта    ctx.fillStyle=col; circle(ctx,256,256,100);   // пример }},
Правила:

рисунок делается в координатах 512×512;
rng() — детерминированный ГПСЧ: чем больше вызовов, тем больше«версий» внутри одного варианта (их перебрасывает кубик в интерфейсе);
каждые 8 вариантов = одна страница плиток в расширенном режиме;
для опциональных слоёв (рамка, акценты, оверлей) вариант {id:'none'}держи первым в массиве.

## Горячие клавиши

Клавиша	Действие
Space	сгенерировать новую аватарку
C	скопировать PNG в буфер обмена
S	скачать PNG
Esc	из галереи — назад в редактор

## Заметки
Избранное хранится в localStorage браузера (ключ geopop.favs.v1).
Копирование в буфер использует Clipboard API; если браузер его не даёт,покажется подсказка скачать файл.
Размеры экспорта: 128/256/512/1024 px — картинка каждый раз рисуетсязаново в нужном разрешении, без растягивания.
